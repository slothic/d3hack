# d3hack -- Greater Rift map tile budgets. Learned from the game, never invented.
#
# Every Greater Rift floor carries three numbers beside its tileset. Worldgen feeds the first
# of them into the loop that decides how many tiles the floor gets, so substituting a map
# without its own three numbers builds the new tileset to the OLD map's budget -- which is
# what produced floors you could walk into and not walk out of.
#
# RiftMapSubstitute therefore refuses to swap in any map that is not listed here. This file is
# the starting set so that a fresh install works from the first rift instead of after a dozen.
# The game adds to it on its own as it rolls maps you have not seen yet; the format is
#
#     <world SNO> <float0 bits> <float1 bits> <float2 bits>
#
# stored as raw IEEE bit patterns because 1.07 does not survive a text round trip exactly.
# Comment lines are ignored on read but are NOT preserved when the game rewrites this file.
#
# Only Greater Rift plans are recorded. Nephalem rift plans use the same three slots for a
# different quantity (they read as identical whole numbers, 2/2/2 through 10/10/10), and
# feeding one of those to a Greater Rift floor is the exact mistake described above.
#
